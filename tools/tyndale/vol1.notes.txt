# The Works of William Tyndale, Vol. I: Doctrinal Treatises (ed. Henry
# Walter, Parker Society, Cambridge, 1848). Marginal notes.
#
# Format:
#   == leaf N | running head | margin side | draft|checked
#   @Y TEXT
# N is the Internet Archive leaf (page index from 0) of
# doctrinaltreatis00tynduoft; Y is the note's first line, in pixels down
# the full-resolution page image, which also places it beside its body line.
#
# ---------------------------------------------------------------------
# Sources and how they were combined
# ---------------------------------------------------------------------
# The IA hOCR is unusable for the margin: the notes are set two lines
# per body line and the OCR dropped or merged every second one. So each
# note was drafted by tools/tyndale/split.mjs (Tesseract 5 on the margin
# strip of the page image), then proofread here against the scan, leaf by
# leaf. A leaf's status turns from "draft" to "checked" only once every
# note on it has been read against the image. "?" in front of a draft
# line marks a note the automatic checks flagged; no "?" survives
# checking.
#
# ---------------------------------------------------------------------
# Correction policy
# ---------------------------------------------------------------------
# - Words, spelling and punctuation as printed, including the edition's
#   old forms ("holp", "spiritualty") and its occasional run-together
#   words ("throughJesus" is printed so, but is written "through Jesus").
# - Line-break hyphens are closed up; a hyphen the compound really has
#   ("belly-cheer", "mercy-stool") is kept.
# - The two attribution marks are written "W. T." (Tyndale's own gloss)
#   and "Ant. ed." (from an earlier edition), whatever the spacing.
# - Citations as printed ("Matt. vi. & vii."); no chapter is supplied
#   that the margin doesn't print.
# - A note continued from the previous page starts with "..."; one that
#   runs onto the next page ends with "...".
# - Handwriting, library marks and show-through from the reverse side are
#   not notes and are left out.
