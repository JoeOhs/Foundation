# [[pdf-page:]] is the page of that file each diagram is on. Notation:
# README.md here. Small-capital words are written in title case.
#
# The book Structure's J2 is the Zechariah member of the Three Prophets
# diagram (p. 1206; see hosea.structure.txt).
#
# Depth notes:
#   - 1. 7—6. 15 (C1): the second A's members are printed at the same
#     steps as the first A's (E, D, C, then B deepest), so they keep those
#     depths; the jump after the bracket line A is legal. The last B
#     (6. 9-15) prints at the same x as the first B (HOCR 1561 vs 1562),
#     three steps right of the C above it; the parser allows one step
#     after a text line, so it is set one level in (depth 3).
#   - 6. 9-15 (B): the second T is printed two steps right of the "o"
#     above it; the parser allows one step after a text line, so it is set
#     one level in (depth 3).
#   - 11. 1-17 (C2): depths follow the HOCR x positions (s < t < Q < u < v
#     in both halves).
