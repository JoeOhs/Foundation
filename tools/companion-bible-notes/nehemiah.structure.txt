# The Companion Bible (E. W. Bullinger, 1913) — Nehemiah
# Structure diagrams, transcribed from the page scans (the images inside
# thecompanionbible_202504_pdf/12. Ezra & Nehemiah_text.pdf, which holds both
# books; Nehemiah is pages 18-38, printed pp. 633-653); [[pdf-page:]] is the
# page of that file each diagram is on. Notation: README.md here. The
# diagrams covering both books (pp. 616-617) are kept in ezra.structure.txt.
#
# Where the second half of a pair prints its members in reverse order
# (1. 1—2. 20 second K: M, L, and second M: i, h; 12. 27-47 second N: R2,
# Q2) both sit at one depth: stepping the first in would make the parser
# hang it under the previous pair's member. In 12. 27-47 the first N prints
# two steps right of O2; it is set one level in. Its last O prints with a
# damaged superscript, read O4 (after O1-O3 and P1-P4): at 1000 dpi it
# lacks the serifed "1" of O1 and leans like the stem of P4's "4", but the
# crossbar is gone, so the reading rests on the sequence. "33 37" (r2, B2)
# and "3 36" (E, heading) print with broken hyphens; read 33-37, 3-36.
# Multi-chapter diagrams are anchored at their first verse.
#
# Checked: all 41 diagrams compared with their scans in structure-review;
# bar-check's 7 flags are glyph-width drift (H1, W1 h/i), an HOCR misread
# (S: W3) and rows matched to the scripture column (J, 12. 1-26).
