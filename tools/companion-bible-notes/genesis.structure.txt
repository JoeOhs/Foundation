# The Companion Bible (E. W. Bullinger, 1913) — Genesis
# Structure diagrams — all 71 that the Genesis pages print. Transcribed
# from the page scans (the images inside
# thecompanionbible_202504_pdf/1. Genesis_text.pdf); [[pdf-page:]] is the
# page of that file each diagram is on. Notation: README.md here.
#
# Where a staircase steps in by two levels after a text line (36. 1-8
# only), the deeper member is set one level in instead: the parser
# only allows a two-level step straight after a bracket line.
#
# In 3. 1-24, H prints right of the bracket G but is not part of it; depth
# follows the printed staircase, so H's parent in the data is G.
#
# In 27. 1—35. 15 the second K prints two steps right of e; the parser
# allows one, so it is set one level in.
#
# A printed reference that reaches outside the diagram's anchor chapter
# (e.g. "2. 4—50. 26") can't be a REF_RANGE, which is verses of one chapter;
# such a line keeps its reference at the head of its TEXT instead, as printed.
