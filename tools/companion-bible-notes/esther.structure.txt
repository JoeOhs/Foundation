# The Companion Bible (E. W. Bullinger, 1913) — Esther
# Structure diagrams, transcribed from the page scans (the images inside
# thecompanionbible_202504_pdf/13. Esther_text.pdf, printed pp. 654-664);
# [[pdf-page:]] is the page of that file each diagram is on. Notation:
# README.md here.
#
# In the whole-book Structure (p. 654) each C prints outside B's bar but one
# step right of the row above it (the second F, H, K, M); as in Isaiah and
# Ecclesiastes it is set one level in from that row. The fourth E
# prints with no superscript and is written "E" as printed. Where the second
# half of a pair prints its members in reverse order (2. 1-20: f2 e2, f3 e3)
# both sit at one depth; likewise 3. 1-15 second E (m, l) and 8. 7-17 second
# z (b, a). In 3. 1-15 each E prints one step right of k and is set one
# level in from it. Multi-chapter diagrams are anchored at their first verse.
#
# Checked: all 15 diagrams compared with their scans; bar-check's 5 flags
# are the documented reversed-pair depths and two 8. 7-17 rows matched to
# the scripture column.
