# The Companion Bible (E. W. Bullinger, 1913) — Ezra
# Structure diagrams, transcribed from the page scans (the images inside
# thecompanionbible_202504_pdf/12. Ezra & Nehemiah_text.pdf, which holds both
# books); [[pdf-page:]] is the page of that file each diagram is on.
# Notation: README.md here. The diagrams on pp. 616-617 cover both books and
# are kept here, the book they open. The table of "Certain fixed points" on
# p. 617 is a two-column table, not an outline, and is not transcribed; the
# page link shows it.
#
# A member printed with two references under one brace (p. 617: P, Q, O) is
# written as one line carrying both references.
#
# Where the second half of a pair prints its two members in reverse order
# (1. 5—2. 70 second B: b, a; 3. 1-7 second E: f, e; 7. 1—8. 36 X4: w4, v4)
# each keeps its printed depth, so the repeated letters line up (the parser
# takes the nearest shallower line as parent, so the stepped-in first member
# still hangs under its own bracket). In the chronological diagram (p. 617)
# the second M prints left of the first; it is set at the first M's depth so
# the two line up.
# "13 25" (W3, Z line, p. 627) is printed with its hyphen broken; read 13-25,
# as in the diagram's own heading.
#
# Checked: every diagram compared with its scan (bar-check flags at p2 N/O,
# p8 F1/F2 and p12 x/y are HOCR misreads; the image shows the depths used).
